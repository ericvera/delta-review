Combined diff tab ("Cluster Changes") stays current

Today the tab is a snapshot: marking a file reviewed leaves it in place until you reopen the tab. After this change, the tab is rebuilt whenever the cluster's needs-review files or their diff bases change: review marks (per-file +, title-bar Mark Cluster Reviewed, folder/cluster/all marks, auto-review), file edits, and agent edits to the clusters file. The tab keeps its title and its place in the editor group.
