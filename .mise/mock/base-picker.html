Base picker

Clicking the status bar base item, or running Delta Review: Set Diff Base for Branch from the Command Palette, opens the picker. The current base is marked with a check. Picking an entry stores an explicit base for the branch, which every worktree on the branch shares, and the view refreshes.

"Use automatic detection" appears only when the branch has an explicit base. Typing filters the branch list. A typed value that matches no entry is offered as "Use ref '<typed>'".
