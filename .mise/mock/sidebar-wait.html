Sidebar: clusters an agent flagged "wait"

Grouped-by-cluster view in the SCM sidebar. The agent set wait: true on "Combined diff refresh" in the clusters contract. That cluster row and every row under it are muted, the way Explorer mutes a git-ignored folder. Order does not change, and nothing is disabled: hover actions (Open Cluster Changes, Mark Reviewed) and the file rows work the same. Unclustered, Auto and Reviewed are never muted.

  "version": 3,

  ]

Version stays 3; an older extension ignores wait and shows the cluster normally.
