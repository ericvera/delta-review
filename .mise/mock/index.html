Document path convention (no contract key names a document; a row appears only when its file exists)
  • Branch document: <git common dir>/delta-review/branch-<branch>.md
  • Cluster notes: <git common dir>/delta-review/cluster-notes-<branch>/<cluster slug>.md — slug is the cluster label lowercased, runs of non-alphanumerics replaced by one hyphen (Clusters contract v4 ⇒ clusters-contract-v4.md). <branch> is sanitized as for clusters-<branch>.json.
