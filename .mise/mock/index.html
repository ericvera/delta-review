Delta Review: cluster review status at a glance

Mock of the Delta Review SCM view in grouped-by-cluster mode. Both variants render the same sample branch so they compare row for row. Cluster order and expansion are unchanged.

Rule: a row is dimmed when there is nothing to review in it right now (fully reviewed, waiting, or empty), at cluster, directory and file level. Not dimmed = ok to review. An hourglass replaces the cluster icon when anything inside is flagged wait; a dimmed cluster without the hourglass is fully reviewed. The x/z count keeps its meaning (reviewed / total). Tree view mode. Unclustered and Auto unchanged.

  • Current behavior: baseline (different sample, list mode): every cluster uses layers; the x/z count is the only review-state signal; wait clusters have a muted label.
  • Variant 2a: hourglass on every waiting row: The hourglass also replaces the icon on waiting file and directory rows (explicitly flagged, or containing a flagged file), plus dimming. Rows inside a cluster-level wait only dim; the cluster carries the hourglass.
  • Variant 2b: hourglass on clusters only: Only cluster rows get the hourglass. Waiting files and directories are only dimmed and keep their normal icons.
  • Side by side: 2a and 2b next to each other.
