Delta Review mock: per-branch diff base

Static mock of the per-branch base UI. The dark theme approximates VS Code, and codicons are shown as text glyphs. Example: the branch feat/per-branch-diff-base was forked from feat/notes-v2, and the fallback deltaReview.baseBranch is main.

  • Status bar: base item shows the new base item next to the review counter in each source state (explicit, auto-detected, fallback), with hover tooltips.
  • Base picker is the quick pick the base item opens. It has detected candidates, local branches, a custom ref, and "Use automatic detection", which clears an explicit base. It also shows the free-text ref input step.
  • Stale base prompt covers a stored or detected base that is fully merged into main. It shows the notification, the status bar warning tint while the prompt is unanswered, and the state after each choice.
  • Base ref missing covers an explicit base that no longer resolves (for example, the branch was deleted). It shows the tree message and the status bar error state, and both point to the picker instead of the setting.
