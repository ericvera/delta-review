Delta Review mock: Open Cluster Changes (combined cluster diff)

Branch feat/move-inherit-and-cluster-delta-diff. Only task 2 changes the UI. Task 1 (moved files inheriting their old path's reviewed snapshot) has no UI of its own; its effect shows on the moved file in both screens.

  • Sidebar: cluster rows
    The new "Open Cluster Changes" inline action and context-menu entry. States: offered (hover and right-click), offered on a fresh never-reviewed cluster, not offered (all reviewed and unchanged, empty), the Unclustered and Auto buckets, and what happens when nothing needs review at click time.
  • Combined diff: multi-diff editor
    One entry per cluster file that needs review, each against its own base (reviewed snapshot, else merge base), with the new "Mark Cluster Reviewed" title-bar button. Includes a moved file whose snapshot came from its old path and a never-reviewed file against the merge base.
  • Click to select: sidebar and combined diff side by side
    Clicking into a file's text in the combined diff selects that file's row in the Delta Review pane, which keeps no keyboard focus, so the row's existing Mark Reviewed button is right there. Clicking only a file's header does not select it.

New elements have a dashed blue outline. Icons are VS Code codicons, using the bundled font copy codicon.ttf.
