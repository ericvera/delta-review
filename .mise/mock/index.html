Delta Review: cluster review status at a glance

Mock of the Delta Review SCM view in grouped-by-cluster mode. Each screen renders the same sample branch so variants compare row for row. Cluster order and expansion are unchanged (contract order; done clusters stay expanded showing "All files reviewed.").

  • Current behavior: Baseline for comparison: every cluster uses the same layers icon; the x/z count is the only review-state signal; wait clusters have a muted label.
  • Variant A: status icon: The cluster icon shows review state: a green check when every file is reviewed, an open circle while files still need review. The label stays full brightness unless wait-flagged.
  • Variant B: dimmed done label: Keeps the layers icon; done clusters get a muted label (same muted color as wait). Note: a done cluster and a wait-flagged pending cluster look alike, since both are muted.
  • Variant C: icon + dimmed label: Both signals: green check plus muted label when done; open circle and full-brightness label while files are pending. A wait flag keeps its muted label; the icon still carries review state.
  • Side by side: all four renderings next to each other.
