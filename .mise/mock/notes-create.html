A new $(add) action sits in the Review Notes title bar, left of Clear Resolved. It is the only pane entry point; file rows get no +. Clicking it opens a quick pick: "File note" (for the active editor's file) or "General note". The gutter + in diffs still creates line notes.

3. After choosing

  • File note: opens (or focuses) the file's review diff and shows an empty whole-file thread at the top, focused for typing. See File note thread.
  • General note: opens a new General note tab in draft state with an empty note box; saving the first comment creates the note and adds it under "General notes" in the pane. Cancelling an empty draft closes the tab and saves nothing.
